# Blog_personel_développeur_web


## 📋 À propos

Projet personnel de développement d'un blog sur le développement web et le partage d'expériences

Contexte : Projet personnel afin de présenter sous forme d'article mes differents apprentissage et expériences dans le developpement web

## ✨ Fonctionnalités principales

- Interface principale proposant l'affichage des articles sous forme de carte a cliquer
- Une page par article
- Darkmode disponible
